# Changelog

## 2.0.0 — 2026-11-09

### Платформы

- Сборки для Linux: AppImage и deb (x64).
- Сборки для macOS: dmg и zip (x64, без подписи).
- GitHub Actions: матрица Windows/Linux/macOS, артефакты и SHA256.
- Плавающий виджет на macOS/Linux (за иконками — только Windows), опция
  «Поверх окон», управление из трея.
- Плавная анимация полоски прогресса в виджете вместо ступенчатой.
- Обе глобальные горячие клавиши настраиваются в параметрах: запись сочетания,
  сброс к значению по умолчанию и проверка конфликтов.
- Повтор задачи выбирается пиксельным списком в стиле приложения.
- У тегов в списке появился крестик для удаления из истории.
- Убрана неиспользуемая кнопка голосового ввода.
- Автозапуск: Windows/macOS через системные настройки, Linux через
  `~/.config/autostart/gonow.desktop`.
- macOS: меню приложения, активация по клику в Dock, template-иконка меню-бара.
- MCP-скрипт копируется в папку данных — стабильный путь для AppImage и macOS.
- Иконки: `build/icon.png`, `build/icon.icns`, иконки трея для macOS/Linux.

## 1.1.1 — 2026-11-09

### Исправления

- Напоминание больше не вспыхивает темой по умолчанию: тема применяется
  синхронно до первого кадра (все окна получают её в URL).
- Тонкая пиксельная рамка фокуса у полей ввода, заметки и поиска вместо
  толстого outline.
- Список тегов — собственная пиксельная панель вместо нативного `datalist`:
  кнопка открывает и закрывает его, стиль совпадает с выбором даты/времени.
- В статистике убран пункт «Серия».

## 1.1.0 — 2026-11-09

### Возможности

- Быстрое добавление по `Ctrl+Alt+Space`: мини-окно у курсора с разбором даты,
  времени, тегов, важности и «без срока» на русском и английском.
- Поиск по заголовку, заметке и тегам сразу по всем датам; фильтры
  «Все / Активные / Выполненные», фильтр по тегу, архив выполненных.
- Флаг «Важное», до пяти тегов на задачу, перетаскивание внутри дня и перенос
  задач между днями в недельном виде.
- Отмена удаления, выполнения и очистки архива через тост.
- Статистика: сделано сегодня, за 7 дней, серия дней и мини-график.
- Горячие клавиши: `N`, `/`, `Ctrl+F`, стрелки, `Space`, `Enter`, `Delete`, `Esc`.
- Настройка автоочистки выполненных (по умолчанию выключена), кнопка открытия
  папки данных.

### Надёжность

- Атомарная запись файла данных (временный файл + `fsync` + переименование).
- Ежедневные резервные копии в `backups/` (хранятся 7) и восстановление из
  `.bak`/`backups/` при повреждённом JSON; повреждённый файл сохраняется.
- MCP: поддержка `important` и `tags` в `add_task`, `add_tasks`, `update_task`,
  поиск по тегам.

## 1.0.0 — 2026-11-05

Первый стабильный релиз.

### Возможности

- Виджет на рабочем столе с закреплением за иконками, перетаскиванием, изменением
  размера и защитой от потери позиции.
- Планер: день/неделя, навигация по датам, добавление, редактирование и удаление
  задач, дата, время, повтор, заметка, «без уведомления».
- Разделы «Незавершённые» и «Без срока», перенос срока на сегодня.
- Напоминания с мягким звуком, кнопками «Сделано»/«+10 мин» и автоотсрочкой.
- Глобальная горячая клавиша (по умолчанию `Alt+Shift+Q`) с открытием/скрытием
  планера и записью нового сочетания в настройках.
- Пиксельный календарь и выбор времени в стиле приложения.
- Растущее поле заметки (до 1000 символов).
- Шесть цветовых тем, русский и английский интерфейс, свой логотип.
- Экспорт и импорт задач в JSON.
- Трей, автозапуск, сворачивание в трей.
- MCP-сервер: `list_tasks`, `add_task`, `add_tasks`, `update_task`,
  `delete_task`; работа через локальный мост или файл.
- Локальное хранение, резервная копия данных, отсутствие телеметрии.

### Сборка

- Установщик NSIS (per-user) и портативная версия.
- Мультиразмерная иконка приложения.
- MIT-лицензия и уведомления о сторонних компонентах.
